Vortex Engine Lua API

What Vortex Engine adds to Psych Engine's Lua. In HScript, game is the PlayState: every setProperty('name', value) here is game.name = value; there.

Lua

Supports all of Psych Engine 1.0.4's Lua

Everything documented on ShadowMario's Psych Engine Lua Script API page works in Vortex Engine the same way: its functions, callbacks, variables and code snippets. This page only lists what Vortex adds on top of it.

Open the Psych Engine Lua API https://shadowmario.github.io/psychengine.lua/

Detecting Vortex Engine

The VortexEngine variable is true on Vortex and nil everywhere else, so one script can work on both.

function onCreate()
    if VortexEngine then
        -- Vortex Engine
    else
        -- Psych Engine or another fork
    end
end
// HScript: reading a variable that doesn't exist is an error on other engines
var isVortex = false;
try { if (VortexEngine == true) isVortex = true; } catch(e) { isVortex = false; }

Variables

VortexEngine Bool

Always true on Vortex Engine (Lua and HScript).

playAsOpponent Bool

"Play as Opponent" is on: the player is hitting the opponent's notes. The sides of the chart don't change: mustPress and goodNoteHit are still the right side's notes, played by the computer. Use the notes' playable property for "the player's notes". The health scripts get is still Boyfriend's, as songs are made, except before the song starts and in noteMiss / noteMissPress.

onlinePlay Bool

The song is an online match of Vortex's multiplayer.

function onCreatePost()
    if onlinePlay then
        close() -- turns this script off for online matches (a mechanic that would be unfair)
    end
end

onlineHost Bool

An online match, and this player is the one hosting it.

If a script stops the countdown (a dialogue, a cutscene) and starts it later with startCountdown(), the two players wait for each other and the song starts at the same time for both. Nothing has to be done in the script for it.

Gameplay

setLaneUnderlay(show:Bool, ?alpha:Float = 0.5)#

Turns the dark lanes under the player's notes on or off and sets how dark they are, whatever the player's option says. Works at any time of the song.

setLaneUnderlay(true, 0.8)
setLaneUnderlay(false)

setScoreCamera(where:String)#

Where the ratings ("Sick!"), the combo numbers and "Combo" pop up: "game" (in the stage, moving and zooming with it) or "hud". The player's option is only the default.

setHiddenNotes(hide:Bool)#

Hides every note, the ones already on the screen too (the "Hidden Notes" gameplay changer), or shows them again. Hit them by memory!

getTallies()#

Returns a table: sick, good, bad, shit, missed, combo, maxCombo, totalNotesHit, totalNotes

What the V-Slice style results screen counts, so far in the song.

local t = getTallies()
debugPrint('Sicks: ' .. t.sick .. ' / ' .. t.totalNotes)

startConversation(name:String)#

Returns true if the conversation was found

Shows a V-Slice dialogue (data/dialogue/conversations/NAME.json of the mod) in a Psych song. Like startDialogue: call it in onStartCountdown (returning Function_Stop) or onEndSong, and the song starts (or ends) when the dialogue is over.

setBlendMode(tag:String, mode:String)More modes#

Psych's function, with more modes: "overlay", "hardlight", "difference" and "invert" really work on Lua sprites, drawn the way V-Slice's cameras draw them.

makeLuaSprite('light', 'stage/light', 0, 0)
setBlendMode('light', 'overlay')
addLuaSprite('light', true)

Cameras

makeLuaCamera(tag:String, ?above:String = 'hud')#

  • tag the camera's name
  • above the camera it goes right over: "game", "hud", "other" or another Lua camera's tag

A camera of the script's own. Sprites go on it with setObjectCamera(sprite, tag), and it's moved, zoomed and tweened by its tag like the song's cameras.

makeLuaCamera('camBG', 'game')        -- between the stage and the HUD
setObjectCamera('fog', 'camBG')
setProperty('camBG.zoom', 1.2)
doTweenZoom('fogZoom', 'camBG', 1, 2, 'quadOut')

removeLuaCamera(tag:String)#

Takes a Lua camera out (what's on it stops being drawn). The song's own cameras can't be removed.

luaCameraExists(tag:String)#

Returns Bool

Turning a camera (setProperty('camGame.angle', 10)) no longer leaves empty corners: scripts like zCameraFix aren't needed.

Shaders on whole cameras

The .frag files of shaders/, the same ones setSpriteShader uses. They need the player's Shaders option on.

addCameraShader(camera:String, shader:String, ?tag:String)#

  • camera "game", "hud", "other" or a Lua camera's tag
  • shader the shader's file name
  • tag what its values are set by (the shader's name if not given)

A camera can have more than one; they're applied in the order they were added. The values are set with the usual functions (setShaderFloat...), using the tag.

addCameraShader('game', 'chromatic', 'chroma')
setShaderFloat('chroma', 'amount', 0.005)

removeCameraShader(camera:String, ?tag:String)#

Takes off the shader with that tag. With no tag, every shader of that camera.

tweenShaderFloat(tag:String, shaderTag:String, property:String, value:Float, duration:Float, ?ease:String = 'linear')#

Changes a float of a shader smoothly (a camera's, or a sprite's by the sprite's tag). onTweenCompleted(tag, shaderTag) is called at the end, and cancelTween(tag) stops it.

tweenShaderFloat('chromaOut', 'chroma', 'amount', 0, 0.5, 'quadOut')

3D

Everything is seen in perspective from the center of the screen. Angles are in degrees.

angleX, angleY, z properties#

  • angleX turned forward/back, around the horizontal line through its origin
  • angleY turned left/right, around the vertical line through its origin
  • z pushed away from the screen (it gets smaller toward the center); negative brings it closer

On Lua sprites, receptors and notes. angle still turns it on the screen as always. Notes copy them from their receptor, long notes too: to turn a note on its own, set its copy3D to false and then its own values.

setProperty('card.angleY', 45)
startTween('cardSpin', 'card', {angleY = 360}, 2, {ease = 'quadInOut'})
setPropertyFromGroup('playerStrums', 0, 'angleX', 60)
setPropertyFromGroup('opponentStrums', 2, 'z', 400)

setCamera3D(camera:String, angleX:Float, angleY:Float, z:Float)#

Turns a whole camera in perspective. All zeros put it back to normal. Turning the HUD tilts the receptors and the notes together (the long notes too), like a 3D modchart. Needs the Shaders option on.

setCamera3D('hud', 30, 0, 0)  -- the HUD leans back

getCamera3D(camera:String)#

Returns a table: angleX, angleY, z

tweenCamera3D(tag:String, camera:String, angleX:Float, angleY:Float, z:Float, duration:Float, ?ease:String = 'linear')#

setCamera3D little by little. onTweenCompleted(tag, camera) at the end, cancelTween(tag) stops it.

tweenCamera3D('lean', 'hud', 0, 25, 0, 1, 'quadOut')

setPerspective(distance:Float)#

How far the eye is from the screen, in pixels (1000 if not changed). Smaller is a stronger perspective. Applies to everything 3D, models too.

3D models (.obj)

makeLuaModel(tag:String, model:String, ?texture:String, ?x:Float = 0, ?y:Float = 0)#

  • model models/NAME.obj of the mod (just "NAME" works)
  • texture an image of images/, painted with the model's texture coordinates (without one it's plain white, which color tints)
  • x, y where its center goes

A 3D model, made to be 200 pixels on its biggest side. Then addLuaSprite(tag, front), setObjectCamera, removeLuaSprite... like a sprite: added behind or in front of the characters like any sprite.

Its properties (setProperty / startTween): x, y, z, angleX, angleY, angle, alpha, color, visible, scrollFactor, and:

  • modelScale pixels per unit of the model
  • lighting true: each triangle is shaded by how much it faces the light
  • ambient how dark the side away from the light gets, 0 to 1 (0.35)
  • cullBack true: triangles facing away aren't drawn (turn it off for open or flat models)
  • triangleCount read only
function onCreatePost()
    makeLuaModel('ring', 'ring', 'ringTexture', 600, 300)
    addLuaSprite('ring', false)
end

function onUpdate(elapsed)
    setProperty('ring.angleY', getProperty('ring.angleY') + elapsed * 90)
end
The triangles are drawn from the farthest to the closest (there's no depth buffer), so models of up to a few thousand triangles work best. Faces with more than 3 corners are split into triangles.

Notes during the song

spawnNote(time:Float, column:Int, mustPress:Bool, ?holdLength:Float = 0, ?noteType:String = '', ?singers:String)#

  • time in milliseconds of the song
  • column from 0 to getKeyCount() - 1
  • mustPress true for the right side's notes (the player's)
  • holdLength in milliseconds (0: not a long note)
  • noteType a note type ('' is a normal note)
  • singers who sings it: "main", "all" or extra characters' tags

A note like the chart's. A note added for a time that already went by comes as a miss. Note types with a script must already be in the song's chart to have their script loaded.

-- 4 notes, one per column, half a second apart, 2 seconds from now
for i = 0, 3 do
    spawnNote(getSongPosition() + 2000 + i * 500, i, true)
end

getKeyCount()#

Returns Int

How many arrows each side has: 4 on most songs, 1 to 9 on songs with extra keys.

Extra characters

Extra characters can be set up in the chart editor (see the modding guide) or added during the song. Scripts get each one by its tag, like a Lua sprite: setProperty('pico2.alpha', 0.5), playAnim('pico2', 'hey', true). A "Change Character" event with the tag as its first value changes that extra character.

addExtraCharacter(tag:String, character:String, ?side:String = 'opponent', ?x:Float = 0, ?y:Float = 0, ?singsAll:Bool = false, ?behind:Bool = false)#

  • side "opponent", "player" or "gf"
  • x, y from the spot of the main character of that side
  • singsAll sings every note of its side
  • behind stands behind the main character

Returns false if the tag is already used or the character doesn't exist

addExtraCharacter('backup', 'pico', 'opponent', -300, 0, true)
playAnim('backup', 'hey', true)

removeExtraCharacter(tag:String)#

Takes it out of the song.

getExtraCharacters()#

Returns a table with the tags of every extra character of the song

The game's window

Whatever a song changes is put back when the song is left.

setWindowTitle(title:String) · getWindowTitle()#

setWindowPosition(x:Int, y:Int) · getWindowX() · getWindowY()#

Not while the game is fullscreen (returns false).

-- the window shakes on every beat of a part of the song
local baseX, baseY
function onSongStart() baseX = getWindowX(); baseY = getWindowY() end
function onBeatHit()
    if curBeat >= 64 and curBeat < 96 then
        setWindowPosition(baseX + getRandomInt(-15, 15), baseY + getRandomInt(-15, 15))
    elseif curBeat == 96 then
        setWindowPosition(baseX, baseY)
    end
end

setWindowSize(width:Int, height:Int) · getWindowWidth() · getWindowHeight()#

Not while the game is fullscreen (returns false).

getScreenWidth() · getScreenHeight()#

The size of the monitor the window is on.

isWindowFullscreen()#

Returns Bool

windowAlert(message:String, ?title:String)#

A message box of the system. The game waits until it's closed.

Callbacks

Called by the engine on Lua and HScript scripts, like Psych's own.

onBreakStart(seconds:Float)#

A part of the song with 3 seconds or more without notes to hit started; seconds is how long it is (in real seconds, playback rate included). Called even if the player turned the Break Timer off.

onBreakEnd()#

The notes are coming again (or the song ended).

-- zoom out during the breaks
function onBreakStart(seconds)
    doTweenZoom('breakZoom', 'camGame', 0.7, 1, 'quadOut')
end
function onBreakEnd()
    doTweenZoom('breakZoom', 'camGame', getProperty('defaultCamZoom'), 0.5, 'quadIn')
end

onConversationEnd(name:String)#

A V-Slice dialogue started with startConversation ended.

Properties

With setProperty / getProperty. Each one starts with the player's option and can be changed at any time of the song.

PropertyTypeWhat it is
iconBopBoolThe health icons bop on the beat.
sustainWiggleBoolThe long notes wiggle (needs Shaders on).
showBreakTimerBoolThe countdown shown when there are 3 seconds or more without notes.
ghostNotesBoolTwo notes of the same character together leave an afterimage of the first pose.
healthDrainFloat, 0 to 2Every note the opponent hits takes health. It never kills: health stops at 0.01.
speedMissBoolEvery miss makes the song 5% faster, up to 2x.
hiddennotesBoolNotes that show up from now on are invisible (setHiddenNotes also hides the ones already there).
showLaneUnderlayBoolShows or hides the lanes (use setLaneUnderlay to make them when the player's option is off).
laneUnderlayAlphaFloat, 0 to 1How dark the lanes are.
totalColumnsInt (read)Arrows per side (same as getKeyCount()).
isRestingBool (read)A break is going on.
maxRestTimeFloat (read)How long the current or last break is, in seconds.
maxComboInt (read)The biggest combo of the song.
scoreCameraString (read)"Game" or "HUD" (change it with setScoreCamera).
isVSliceStageBool (read)The stage is a V-Slice stage.
playableCharacterCharacterThe character the player is playing (Boyfriend, or the opponent with Play as Opponent).
otherCharacterCharacterThe one singing by itself.

On notes (getPropertyFromGroup('notes', i, ...)): playable (the player has to hit it, also with Play as Opponent), singers (who sings it), copy3D, angleX, angleY, z.

On the health icons (iconP1 / iconP2): autoUpdate (false: the game stops placing and bopping it), isAnimated and hasWinningIcon (read only).

Objects of Vortex

Vortex's own things, to move, recolor or hide like any other sprite.

NameWhat it is
restCountdownTxt, restTimerBar, restportraitThe Break Timer's text, bar and picture.
keystrokesThe Keystrokes display (null when the option is off).
laneUnderlaysThe lanes (a group).
camSus, camLanesThe cameras of the long notes and of the lanes (under the HUD's).
camOverlayThe camera over every other one, with the keystrokes and the Break Timer.

setProperty('restCountdownTxt.color', getColorFromHex('FF66CC'))
setPropertyFromGroup('laneUnderlays', 0, 'color', getColorFromHex('220033'))
setProperty('susWiggle.waveAmplitude', 0.15)

HScript

HScript reaches everything above directly (game.spawnNote(...), game.addExtraCharacter(...), FlxG.cameras, FlxG.stage.window), and has a few things of its own:

FlxColor.fromString('0x80FF0000');         // "0xAARRGGBB" and "#RRGGBB", with alpha too
FlxColor.interpolate(color1, color2, 0.5); // a color between two others
FlxColor.gradient(color1, color2, 10);     // a list of 10 colors from one to the other

game.playableCharacter; game.otherCharacter; // the one being played and the one singing by itself
game.playableStrums; game.otherStrums;       // the receptors of each
game.makeStrumsEarly();  // in onCreatePost: the receptors now, to move them before the song
game.extraCharacters;    // a list: .tag, .side, .char
game.getExtraCharacter('pico2').char;

Menus and the loading screen have scripts of their own: see state scripts.

Making a mod for other engines too

Everything on this page only exists in Vortex Engine. The mods menu has a CHECK MOD button: it reads a mod's scripts, charts and icons and lists everything it uses that only Vortex has, with the file and line of each one.

LevelMeaning
ERROROther engines stop the script there (a function only Vortex has).
DIFFERENTIt works differently or not at all there (callbacks, properties, blend modes, extra characters).
NOTEUsually fine (a variable that is just nil there, an option that reads as nothing).

A mod with no ERROR or DIFFERENT should also work on Psych Engine 1.0.4. Checking the VortexEngine variable before using something is how a script can work on both.
