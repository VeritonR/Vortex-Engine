About this list

  • The base game's songs (all 35 V-Slice songs, Erect and Pico included) are tested the same way after every change.
  • Mods made for Psych Engine (1.0, and 0.4 to 0.7.3) aren't on this list: they run on Vortex Engine's own Psych code, so they work like they do on Psych Engine.
  • Mods made for phones (images only in .astc) only work on the Android version. On a computer, the game warns about them in hxc_errors.txt.
  • Whatever goes wrong with a mod's scripts is written to hxc_errors.txt, next to the game (on Android, in Android/media/com.team.vortexengine/).
A mod doesn't work, or it's not here? Report it on GitHub with the "A mod doesn't work" form: say where to download it and send your hxc_errors.txt. Fixes made for one mod help every other mod too.
